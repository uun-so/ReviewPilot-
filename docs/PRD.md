# ReviewPilot 产品需求文档
 
版本：v0.1
项目：ReviewPilot — AI 技术文档事实核验 Agent
 
## 1. 产品概述
 
ReviewPilot 是面向技术内容的、知识库严格约束式事实核验工具。
 
#### 解决行业痛点：
 
- AI 生成的技术文档、教程、代码解释大量存在幻觉、参数错误、API 描述错误
- 通用大模型无法“只读指定知识库”，容易混入外部知识
- 市面工具缺少逐句原子级事实校验、证据溯源、标准化评测体系
 
#### 本产品核心准则：
所有判定必须来源于用户提供的知识库，无证据不妄判，有冲突必指出。
 
## 2. 用户群体
 
目标用户：个人技术读者 / 技术编辑
 - 使用场景：在自己本地机器上，针对单篇文章做事实核验
 -  v0.1 不做：团队多人协作服务、账号系统、共享知识库
 -  Web UI 延后到 v2 版本
 
## 3. 产品能力范围（In Scope v0.1）
 
- 自定义知识库构建、分词、全文检索索引
- 文章自动分句、原子主张抽取
- 基于知识库证据的事实核验
- 三级校验机制：格式校验、证据匹配校验、独立复核校验
- 输出结构化 JSON 结果 + 可视化 Markdown 报告
- 完整自动化评测流水线（金标数据集对比）
- 支持并发评测、成本控制、错误降级
 
## 4. 不在本期范围（Out of Scope）
 
- 无 Web UI、无前端页面
- 无多跳推理、跨文档复杂推理
- 暂不支持 PDF、Word 解析
- 不支持向量检索（v0.2 迭代）
 
## 5. 核心功能详细需求
 
5.1 知识库管理
 
- 支持批量导入  .md / .txt / .html 
- 自动分词、建立本地 FTS5 索引
- 支持查看索引状态、重新索引、清空索引
- 完全本地可复现，不依赖云端库
 
5.2 主张抽取
 
自动识别文章中所有可被证真/证伪的技术主张：
 
- 参数默认值
- 函数用法
- 语法规则
- 模块行为
- 版本特性描述
 
自动过滤：抒情、建议、展望、主观观点。
 
5.3 事实核验核心逻辑
 
每条主张必须经过三道校验：
 
1. Schema 合规校验（输出格式统一、无幻觉自由文本）
2. 证据片段严格匹配校验（必须有原文依据）
3. 独立二次核验（防单次模型随机错误）
 
5.4 输出产物
 
-  report.md ：可读评审报告（面试展示用）
-  result.json ：结构化结果（评测、二次开发）
-  trace.jsonl ：完整可复现日志
 
5.5 评测系统
 
- 支持金标数据集自动对比
- 输出准确率、精确率、召回率
- 批量自动化测试、42+ 单元测试保障稳定
 
## 6. 状态定义
 
- 支持（S）：知识库有明确原文证据匹配
- 冲突（C）：知识库存在相反、矛盾描述
- 存疑（U）：证据不足、信息缺失、无法判定
- 未核验（N）：主观语句、无法证伪内容
 
## 7. 非功能需求
 
- 可复现：记录知识库哈希、模型参数、提示词版本
- 高可控：所有判定可溯源
- 安全：密钥不入日志
- 稳定：自动降并发、异常降级
- 可扩展：支持未来向量检索、多模态、WebUI
 
## 8. 版本迭代规划
 
- v0.1：完整 CLI 核验体系 + 评测体系（当前完成）
- v0.2：Embedding 混合检索、更精准匹配，Web 界面、可视化报告，PDF 解析、多跳推理、批量文档审核
